# v3.9.55

本版把账号页剩下的 UISpec 缺口做完：**一个动作一个动词**、**状态筛选说人话**、**抽屉分层**、**探测结果可达**、**用量页人话**、**登录分步**。没有协议兼容性破坏。

## 用户可感知

- **动词与落点一致**：头部 `登录` / `导入` / `粘贴凭证` 各开各的；modal 标题随 tab 变化（含 reauth 邮箱）；探测/刷新用同一套动词。
- **状态筛选 4 组**：`全部 / 正常 / 已停用 / 需处理`，`需处理` 与 KPI 用同一谓词；原始 10 个状态收进 `更多状态`；重复的 `仅异常` 删除。
- **抽屉分层**：主卡 `订阅信息 → 配额使用 → 可用模型 → 请求历史`；6 张技术卡折叠进 `技术详情`，展开状态记住（sessionStorage）。
- **行内上次检查**：每行第二行显示上次探测时间/结果/人话跳过原因，可直接重试；车队面板列出每一次尝试（结果/原因/时间）、`本次结果` 可重开、被排除的非活跃账号单独列出。
- **用量页人话**：`本周期剩余 → 已用 → 限额 → 最近一天`，ACU 有定义，`工作区` 取代 org 术语，原始错误码只在 `title`。
- **登录分步**：第一步两张方法卡 + Token 链接；一次只显示一个表单；代理/密码/历史收进 `高级`；Token 路径每步一个按钮。
