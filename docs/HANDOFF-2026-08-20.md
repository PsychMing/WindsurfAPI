## 1. 接手三分钟内会踩的

1. **不要在 `master` 上 `git commit`。** `.githooks/pre-commit` 会拒,且发生在 `git add` 之后,树会脏。流程:分支 → 审 → `git merge --ff-only` → push。
2. **`npm test` 不是发布门。** 权威是 `npm run test:release`。突变规格 **不在** `npm test` 里;改 `src/` 必须 `for s in test/mutations/*.json; do npm run mutate -- "$s"; done`(Linux,要 `/usr/bin/git`)。
3. **不要打开、不要打印** `.env` / `accounts*` / `*session.env`。家里云 `/home/dwgx_user/WindsurfAPI` 带凭据,systemd `windsurfapi` 听 `0.0.0.0:3003`。覆盖该树仍要 Owner 点名。OTA 跟 annotated tag（v3.9.29 起）。门禁用 `~/scratch/` 隔离克隆。
