## 1. 接手三分钟内会踩的

1. **不要在 `master` 上 `git commit`。** `.githooks/pre-commit` 会拒,且发生在 `git add` 之后,树会脏。
2. **`npm test` 不是发布门。** 权威是 `npm run test:release`;突变规格**不在**套件里(改 `src/` 要跑 `for s in test/mutations/*.json; do npm run mutate -- "$s"; done`,Linux)。
3. **不要打开、不要打印** `.env` / `accounts*` / `*session.env`。OTA 跟 annotated tag;家里云已弃用(Owner 2026-09-04)。
4. **本版新发现的坑**:`test/docs-consistency-guard.test.js` 会走**整棵工作树**找 `.md`(不认 gitignore)——往 `tmp/` 丢带相对链接的 markdown 会让本机全量套件变红(CI 是干净 checkout,不受影响)。把 `tmp/` 清掉即可。
