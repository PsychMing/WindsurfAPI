## 1. 接手三分钟内会踩的

1. **不要在 `master` 上 `git commit`**(`.githooks/pre-commit` 拒,且发生在 `git add` 之后)。分支 → ff-only。
2. **`npm test` 不是发布门**;权威是 `npm run test:release`(Linux)。突变规格不在套件里。
3. **不要打开/打印** `.env` / `accounts*` / `*session.env`。OTA 跟 annotated tag。
4. **`docs-consistency-guard` 现在只扫 git 跟踪的 markdown**——但 `scripts/` 是**白名单制**
   (`.gitignore` 里 `scripts/*` + 逐条 `!scripts/<name>`):新脚本不加白名单就永远进不了提交。
5. **`test/_research/` 被显式排除**在可运行集之外(研究笔记,期望值过期)。往里放 `.test.js` 不会被执行。

## 2. v3.9.36 改了什么

四条线(细节见 [releases/RELEASE_NOTES_3.9.36.md](releases/RELEASE_NOTES_3.9.36.md)):

1. **PR #271**(贡献者):并行 `tool_calls` 之间的游离 assistant 文本折进交错块;评审后补掉丢图、
   空 ID 配对、字段丢失三处。

   (并把它从 `structuredClone` 换成只复制容器:3 MB 载荷 put 2.79→0.10 ms)、JWT 缓存淘汰、
   流失败分层 + 转移间隔。
4. **安全**:凭据库唯一 tmp + 串行写 + 拒绝缩水修复 + 死写者锁回收、登录 `credentialStored`、
   可信客户端 IP、主机白名单(带分类,不耗账号错误预算)、stats 导入原型键、日志脱敏。
